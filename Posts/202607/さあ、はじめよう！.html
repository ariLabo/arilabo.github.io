#仕事 #python

仕事にやる気がでないのは愚痴を言えないということもあるだろうということで、匿名で愚痴を言うサイトを作った。

github pagesの静的サイトを使うのだけれど、これまではpelicanでローカルでGitを通してGithub pagesにプッシュしなければいけないというやり方だったので、

いつも途中で更新することは無くなった。

それを回避すべく、色々と試行錯誤した結果、

Github Actionを使って、色々な形で作られたHTMLファイルを強制的にGithub Pagesにアップするという形にした。

Github Actionはgithubのレポジトリにアップされたファイルを自動的に整形し、index.htmlに記事として貼り付け、さらにはタグ機能も付与する。

おそらくこのFacebookで書いた記事もGithubのリポジトリにHtmlファイルとしてアップすれば、自動的にブログの記事になる。
